# 2026-09-07 実データ取込に伴うスキーマ調整と未確定事項

`職員シフト作成` フォルダの [職員基本情報2026-9.pdf](../../../../職員シフト作成/職員基本情報2026-9.pdf)(全32名分の実データ)を職員マスタに取り込むにあたり、キックオフ時に作成した初期スキーマと実データの間に以下の食い違いが見つかったため、スキーマを実データに合わせて調整した。

## 1. 運転可能量区分: 7段階(a〜g) → 8段階(A〜H)に変更

- 職員情報マスター登録の原資料では a〜g の7段階(1.5<A<2.0 〜 A<0.8)と定義されていた。
- 実データの「運転区分」列は A〜H の8段階で、`BAND_1`〜`BAND_7` という当初の実装では表現できなかった。
- 対応: `DrivingCapacityBand` enumを `BAND_A`〜`BAND_H` に変更(A〜Gは原資料のa〜gの数値範囲をそのまま踏襲)。
- **未確定**: `H` の正式な定義は不明。実データではほぼ全てのアルバイト職員に付与されており、「運転業務なし(対象外)」を意味する可能性が高いが、要確認。

## 2. 職制区分を必須項目→任意項目に変更

- 実データで「システム管理者」区分の職員(石村匠・石村晃一)は職制欄が空欄だった。
- 対応: `Staff.employmentType` を `StaffEmploymentType?`(任意)に変更。

## 3. 「区分」列とマスタ項目②権限設定・③職制区分の対応関係(未確定)

実データの「区分」列は システム管理者/管理者/一般職員/パート/アルバイト の5値だが、原資料の権限設定は システム管理者/管理者/予定作成者/一般職員 の4区分。「パート」「アルバイト」は権限設定の選択肢に存在しない。

取込にあたり、以下の推定でマッピングした(**要確認**):

| 実データの「区分」 | 登録したpermissionLevel | 備考 |
| --- | --- | --- |
| システム管理者 | SYSTEM_ADMIN | |
| 管理者 | ADMIN | |
| 一般職員 | GENERAL_STAFF | |
| パート | GENERAL_STAFF | 権限的には一般職員相当と仮定 |
| アルバイト | GENERAL_STAFF | 権限的には一般職員相当と仮定 |

「予定作成者(PLANNER)」に該当する職員は今回のデータには存在しなかった。

また、有川茜・臺勝好の2名は「区分」がパートである一方「職制」は正社員(週40時間)になっており、区分と職制が一致していない。実データをそのまま転記したが、意図した組み合わせか要確認。
